# Aura by Preethi

Premium-inspired responsive fashion storefront using the supplied burgundy-and-gold identity.

## Features
- Responsive homepage and fashion category navigation
- Sample saree and blouse catalogue
- Product search, category filters and price sorting
- Wishlist toggles and browser-local demo shopping bag
- Animated section reveals with reduced-motion support
- No Node.js, npm, VS Code or build process required

## Website source
- `index.html`: entire static storefront (HTML, CSS and JavaScript)
- `assets/aura-logo.svg`: Aura by Preethi logo artwork

## Publish with GitHub Pages (one-time account setting)
1. Open the repository's **Settings → Pages**: https://github.com/sriramta30-star/aura-by-preethi/settings/pages
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then click **Save**.
4. Wait for GitHub Pages to finish publishing. The permanent site address should be:
   https://sriramta30-star.github.io/aura-by-preethi/

This account's connected GitHub integration can commit website files but cannot activate Pages settings automatically, so that one-time setting must be saved by the repository owner.

## Demo-only notice
Product names, prices, and availability are examples. The shopping bag works only in this browser and does not submit orders. Customer accounts, secure admin access, real inventory/orders, shipping, and payment checkout are not implemented. Do not accept real orders or payments until those systems are configured. Product photography is loaded from external image URLs and requires internet access.
