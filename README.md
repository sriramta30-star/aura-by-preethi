# Aura by Preethi

A responsive fashion storefront concept with an ivory, burgundy and muted-gold identity.

## Website
- Static HTML, CSS and JavaScript: no Node.js, npm, or VS Code is required to preview or host.
- Responsive homepage, category navigation, sample product catalogue, product search, category filtering and price sorting.
- Browser-local demo cart and wishlist interactions.
- GitHub Pages deployment workflow in `.github/workflows/deploy.yml`.

## Publish
The workflow attempts to configure and deploy this repository to GitHub Pages automatically when code is pushed to `main`. After the first workflow completes, check **Actions** for the deployment result and **Settings → Pages** for the published URL. Typical URL: https://sriramta30-star.github.io/aura-by-preethi/

## Demo-only notice
Sample products and prices are placeholders. The cart does not create real orders. Customer accounts, inventory synchronization, a secured admin dashboard, order management, shipping rules and payment processing must be built and connected before production sales. Product photography is loaded from external image URLs and therefore needs an internet connection.
